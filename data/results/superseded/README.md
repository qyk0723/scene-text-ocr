## ⚠️ `eval_medium_v2.md` 为什么是错的

它的文件头写着「模型：PP-OCRv6 medium（det + rec）」，但：

1. **生成时间 2026-10-05 21:42:35**，而**同一秒**的日志（现位于 `logs/remeasure.log`，21:42:36）
   记录的加载模型是 **`PP-OCRv6_small_det` + `PP-OCRv6_small_rec`**。
2. 它的检测指标与 `eval_small_v2.md` **逐位相同**：Pred 1936、匹配 1097、P 56.66 / R 20.98 / F1 30.62。
   两个不同模型不可能产生完全一致的框数与匹配数。

**根因**：`evaluate.py` 的 `--model medium` 分支当时不生效（`else: kwargs = PP-OCRv6_medium_*`
直到 21:43:24 才补上，正好晚 49 秒），于是 `--model medium` 回落到 `config.yaml` 里的 small。
该缺陷已在提交 `afbe1ca` 修复；现在 `--model medium` / `--model small` 会正确解析。
